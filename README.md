O projeto consiste em uma solução para gestão de consultas médicas, dividida em quatros serviços principais que se comunicam de forma assíncrona para garantir disponibilidade e consistência eventual

Pré requisito para execução

•	Docker e Docker Compose instalado;
•	Java 25 se for rodar localmente o projeto;

No diretório local localizado dentro do projeto em o docker-compose.yml
No prompt de comando acessar o diretório onde está o docker-compose.yml e executar o seguinte comando: docker-compose up -d
